# Card UI — every recording its own card (2026-11-09)

**Goal:** the main window becomes a list of dictation cards (chat style): one card per recording,
kept forever, click a card to copy it; the AI round-trip shows inside the active card as a progress
bar; silence auto-stops (~4 s) by default.

**Approved in chat** (design sketch shown). Swift only — server, protocol and history file format
unchanged.

## Decisions

- `Card { id, ts, text, isFinal }` replaces `cleanedFull` in the view model; the last non-final
  card is the active recording. Cards never clear.
- Launch loads the last 50 history entries as final cards (`clean ?? raw`), oldest top, newest
  bottom, auto-scroll to the new card.
- Card tap = copy that card (+ brief "copied" flash). Clipboard still gets every `clean_all` of
  the active card, as today.
- AI state lives in the active card: orange pulsing dot + «در حال ویرایش…» + thin linear
  `ProgressView` (indeterminate — the API gives no percentage). Status row keeps only the phase.
- Auto-stop: `stopAfter = 4` (3 s cut + 1 s), default **on** (stored pref wins, so an explicit
  earlier "off" is respected). Checkbox stays.
- Empty recording (no speech): the blank card is dropped, no history entry — same as server.
- `Clear` button and `clear()` removed from the main window (contradicts "cards are kept");
  History panel keeps its own Clear + search.
- Re-clean targets the last card (server session text); enabled when it has text.
