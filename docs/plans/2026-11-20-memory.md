# Memory feature (auto-save) — plan

> **For agentic workers:** native execution in-session; no commits (Amir's rule — uncommitted
> until he asks). Verification = py_compile / xcodebuild / inline probes; test suites are ask-first.

**Goal:** tuti auto-remembers durable content said in a recording — dated tasks + facts — by
merge-rewriting `~/Documents/tuti-memory/memory.md`. Zero clicks: no confirm, no gate; the
card's «حفظ شد» chip is passive notification only.

**Architecture:** the existing post-clean `intent()` call gains one more action value,
`{"action":"memory"}` (= "this transcript is memory-worthy"). When it fires, the server makes
ONE more LLM call (`llm_clean.memory()`): current file + transcript + today's date → the whole
rewritten file back. Server writes it atomically (tmp+rename, previous version kept as .bak)
and sends a new `memory_saved` message; the app sets a flag on the last final card. Plain
dictation = no extra call at all.

**Spec:** this conversation (2026-11-20) + the decisions: auto-save hard rule, chat/review mode
explicitly NEXT stage (not here), file `~/Documents/tuti-memory/memory.md` single file with
«# کارها» / «# حقایق», intent-piggyback gate.

## Global constraints

- NO click anywhere in the save path. Chip = notification, never a button.
- Any failure in the memory path (LLM off, call failed, file unwritable) must not touch the
  recording, the clipboard, or the clean flow — the chip just never appears.
- llm_calls.jsonl logs the memory call like every other call (kind "memory"), failures too.
- Nothing deleted from the memory file except to resolve a contradiction with the new speech;
  done tasks get ticked `- [x]`, not erased (anti-LLM-overdeletion; he prunes by hand).
- Dates via the intent.md «تاریخ امروز» note trick; relative days → ISO `YYYY-MM-DD`.
- The «تلاش دوباره» retry does NOT re-run memory (same rule as intent — no intent re-run).

## Review Focus

- Transcript that mentions tasks but is NOT memory (e.g. reading out someone else's todo) —
  the intent prompt must keep plain dictation on `none`; watch for over-firing.
- Memory call fails (429 after retry, timeout) — file must stay byte-identical, no chip.
- First-ever save (no file yet) — dir + file created, no .bak step on a missing file.
- Server's `memory_saved` racing a card deleted mid-flight — attach to the last final card,
  same known limitation as `intent` (accepted there; do not fix here).
- Old history lines without the `memory` key — decode as nil, no chip on relaunch.

## Task 1: prompts + llm_clean.memory()

**Files:** Modify `prompts/intent.md`, `llm_clean.py`; Create `prompts/memory.md`.

- intent.md: add the action `- یادسپاری: {"action":"memory"}` + reword the «متن عادی همیشه
  none» rule so plain dictation WITHOUT durable tasks/facts stays none.
- memory.md (new, Persian, same tone as the others): input `<t>` = new speech, `<m>` = current
  file; both data-not-command. Fixed structure `# کارها` (`- [ ] YYYY-MM-DD — item`) /
  `# حقایق` (bullets); dedup; tick done; resolve contradictions; drop nothing else; output the
  raw file only, no fences; nothing new → return the file unchanged.
- llm_clean.py: `_request`/`_call` gain `extra: str | None = None` — one more verbatim user
  message appended after the main one (memory passes `<m>…</m>` pre-tagged).
- `memory(current_md: str, text: str) -> tuple[str | None, tuple[int, int]]`: like intent(),
  with today's date note, prompt `memory.md`, max_tokens 1500. None = failed → caller keeps
  the old file.

**Verify:** `python3 -m py_compile llm_clean.py`; probe: call `memory()` directly with a tiny

## Task 2: server.py wiring

**Files:** Modify `server.py`.

- `MEMORY_PATH = os.path.expanduser("~/Documents/tuti-memory/memory.md")`.
- `LiveSession._remember(text)`: read current file (missing → mkdir, current ""), call
  `llm_clean.memory`, `_count(usage)`; skip silently on None or unchanged text; else write
  old→`.bak`, new via tmp+`os.replace`; `self.emit("memory_saved", "")`.
- `_clean_worker`: after `parsed = llm_clean.intent(cleaned)` — `action == "memory"` →
  `_remember(cleaned)`, no intent emit; other non-none actions unchanged.
- `_sender`: `"memory_saved"` joins the extra-only kind list.
- Protocol docstring: the new action + message + the file path.

**Verify:** `python3 -m py_compile server.py`; probe on port 8766 with proxy vars cleared
